3. Run directed test معين

مثلاً:

TEST=local_basic_test
mkdir -p logs/vcs_directed
./simv +TESTNAME=$TEST -l logs/vcs_directed/${TEST}.log

شوفي نتيجته:

grep "TEST RESULT" logs/vcs_directed/${TEST}.log

شوفي تفاصيل الفشل:

grep -i "fail\|error\|mismatch" logs/vcs_directed/${TEST}.log


4. Run random_all_cases_test
mkdir -p logs/vcs_random
./simv +TESTNAME=random_all_cases_test +NUM_PER_CASE=2 +ntb_random_seed=random -l logs/vcs_random/random_all_cases_test.log

شوفي كل نتائج الراندوم:

grep "RANDOM_CASE_RESULT" logs/vcs_random/random_all_cases_test.log




5. أشوف نتيجة random case معينة

CASE="random_local_frag_zero_drop[1]"

CASE="random_local_frag_zero_drop[1]"
grep "RANDOM_CASE_RESULT" logs/vcs_random/random_all_cases_test.log | grep -F "$CASE"
